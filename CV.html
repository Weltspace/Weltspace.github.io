Locally Private Subgraph Counting: Noisy Adjacency Matrix and DP on Randomized Data 局部差分隐私下的子图计数：噪声邻接矩阵与随机化数据上的差分隐私
2023.04 - present至今
First author|Under review at USENIX Security 2027|Preprint arXiv:2507.06508|Code open-sourced|Leader of National-Level Innovation Training Program (top 3/130) 第一作者｜在投 USENIX Security 2027｜预印本 arXiv:2507.06508｜代码已开源｜国家级大创项目负责人（结题 Top 3/130）
  • Proposed dual frameworks — Noisy Adjacency Matrix (NAM) and Differential Privacy on Randomized Data (DPRD): NAM reformulates edge-LDP subgraph counting as algebraic estimation over randomized matrices; DPRD resolves privacy composition when later rounds consume randomized outputs — strict edge-LDP without any trusted server or shuffler. 提出噪声邻接矩阵（NAM）与随机化数据上的差分隐私（DPRD）双框架：将 edge-LDP 下的子图计数转化为随机化矩阵上的代数估计问题，并解决交互式协议中后轮输入依赖随机化输出的隐私证明难题，在不依赖可信服务器 / Shuffler 的前提下实现严格 edge-LDP 保证。
  • Designed one/two-round estimators (TriOR, TriMTR, QuaTR, TriTR*); gave the first exact closed-form MSE for the RR-based one-round triangle estimator class and the first relative-error guarantee for private subgraph counting. 设计 TriOR、TriMTR、QuaTR、TriTR* 等一轮 / 二轮算法；给出 RR 型一轮三角计数类的首个精确闭式 MSE，以及私有子图计数领域的首个相对误差理论保证——当聚类系数与平均度稳定时，误差不随图规模增长。
  • Ran full experiments on real graphs (Facebook, CA-AstroPh) with privacy-budget sweeps and SOTA comparisons: at ε=1, TriMTR and QuaTR cut relative error to 0.0198×–0.0066× (up to ~150× more accurate) and 0.1963×–0.4407× of the strongest baselines; TriTR* beats TriTR at equal download cost. 实现覆盖真实图数据集（Facebook、CA-AstroPh）、隐私预算扫描与 SOTA 对比的完整实验流程：ε=1 时，TriMTR 与 QuaTR 的相对误差分别降至最强基线的 0.0198×-0.0066×（最高约 150 倍提升）与 0.1963×-0.4407×；TriTR* 在同等下载开销下优于等价于 TDP-VC 的 TriTR。
  • As first author and project leader: problem formulation, algorithm design, theoretical proofs, implementation, experiments, and paper writing. 作为第一作者与项目负责人，负责问题建模、算法设计、理论证明、代码实现、实验评估与论文写作。
