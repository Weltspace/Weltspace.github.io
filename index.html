Research科研

In Submission在投
Locally Private Subgraph Counting via Noisy Adjacency Matrix and Differential Privacy on Randomized Data
Jintao Guo, Ying Zhou, GuiXun Luo, Chao Li, Yan Hu
Under review在投 USENIX Security 2027 · Preprint on arXiv since July 2025 USENIX Security 2027 · 2025 年 7 月起预印本见 arXiv
arXiv Code (anonymized for review)代码（匿名评审版）

Subgraph counting (triangles, 4-cycles) is a fundamental primitive in graph analytics, yet existing edge-LDP protocols force a harsh trade-off between privacy trust assumptions, accuracy, and communication cost. I lead the design of a dual-framework architecture — Noisy Adjacency Matrix (NAM) and Differential Privacy on Randomized Data (DPRD) — that achieves strict edge-LDP without any trusted server or shuffler. 子图计数（三角形、四边形）是图分析的基础原语，但现有 edge-LDP 协议在隐私信任假设、精度与通信开销之间难以兼顾。我主导设计了双框架架构——噪声邻接矩阵（NAM）与随机化数据上的差分隐私（DPRD）——在不依赖任何可信服务器或 Shuffler 的前提下实现严格的 edge-LDP 保证。

  • Frameworks. NAM reformulates private subgraph counting as algebraic estimation over randomized matrices; DPRD resolves the privacy-composition challenge when a later-round mechanism takes randomized data as input. 框架。NAM 将私有子图计数重构为随机化矩阵上的代数估计问题；DPRD 解决了后轮机制以随机化数据为输入时的隐私组合证明难题。
  • Algorithms. One- and two-round estimators for triangle and quadrangle counting: TriOR, TriMTR, QuaTR, and TriTR*. 算法。面向三角形与四边形计数的一轮 / 二轮估计器：TriOR、TriMTR、QuaTR、TriTR*。
  • Theory. The first exact closed-form MSE for the RR-based one-round triangle estimator class, and the first relative-error guarantee for private subgraph counting — error does not grow with graph size when the clustering coefficient and average degree are stable. 理论。给出 RR 型一轮三角计数类的首个精确闭式 MSE，以及私有子图计数领域的首个相对误差理论保证——当聚类系数与平均度稳定时，误差不随图规模增长。
  • Experiments. At ε = 1, TriMTR and QuaTR reduce relative error to 0.0198×–0.0066× and 0.1963×–0.4407× of the strongest baselines (up to ~150× more accurate), outperforming all evaluated edge-LDP and shuffle-model methods. 实验。在 ε = 1 下，TriMTR 与 QuaTR 将相对误差降至最强基线的 0.0198×–0.0066× 与 0.1963×–0.4407×（最高约 150 倍精度提升），优于所有被评估的 edge-LDP 与 shuffle 模型方法。
  • My role. Problem formulation, algorithm design, theoretical proofs, implementation, experiments, and paper writing, as first author and project leader of a National-Level Undergraduate Innovation Training Program (top 3 of 130 projects at completion). 我的角色。作为第一作者与国家级大创项目负责人（结题 Top 3/130），负责问题建模、算法设计、理论证明、代码实现、实验评估与论文写作。

Fine-tuning LLMs to Solve the k-Secretary Problem 微调大语言模型求解 k-Secretary 问题
Course · AI + OR课程项目 · AI + OR 2025.11 – 2026.01
Qwen2.5-1.5B / 7B · SFT + LoRA

Formulate the k-Secretary problem as sequential accept/reject decisions for an LLM. Training sequences are generated from the optimal policy, with state variables (current candidate, past outcomes, remaining slots) injected into the prompt. Fine-tuned Qwen2.5 with SFT + LoRA and built a per-round evaluation pipeline with sequence-level reward — the fine-tuned model clearly outperforms its untuned counterpart, and achieves a higher median score than the OR-optimal policy in some settings. 将运筹学 k-Secretary 问题转化为 LLM 逐候选人「接受 / 拒绝」的顺序决策任务：基于最优策略生成训练序列，在 prompt 中注入当前候选人、历史结果、剩余名额等状态变量；使用 SFT + LoRA 微调 Qwen2.5 系列模型，搭建逐轮决策评测流程并计算序列级 reward。微调后模型显著优于未微调模型；期望收益低于 OR 最优策略，但部分设置下得分中位数更高。

CNN & ResNet Image Classification from Scratch 从零手写 CNN 与 ResNet 图像分类
Deep Learning Course深度学习课程项目 2025.11 – 2026.01
PyTorch / NumPy · FashionMNIST

Implement forward/backward passes, convolution, pooling, BatchNorm, residual connections and optimizers in pure NumPy, aligned in structure and training logic with PyTorch versions. Compare training stability, convergence speed and accuracy on FashionMNIST: ~91% for CNN and ~96% for ResNet, with loss/accuracy curves and confusion matrices analyzing model capacity, residual structure and training details. 用 NumPy 从零实现前向 / 反向传播、卷积、池化、BatchNorm、残差连接与优化器，并与 PyTorch 框架版本对齐结构和训练逻辑；在 FashionMNIST 上对比两框架的训练稳定性、收敛速度与精度：CNN 约 91%，ResNet 约 96%；整理 loss / accuracy 曲线与混淆矩阵，分析模型容量、残差结构与训练细节的影响。

Speech Prediction with Neural Audio Codec Tokens 基于神经音频 Codec Token 的语音预测
DL Final Project深度学习 Final Project 2026.03 – 2026.04
PyTorch · EnCodec / FACodec · sequence prediction

Convert speech waveforms into discrete tokens with EnCodec / FACodec and build a complete "history token → future token" prediction pipeline. Trained sequence models are decoded back to audio and evaluated with objective metrics (STOI, PESQ) plus subjective listening tests, summarizing how token representation, generation length, model capacity and data scale affect quality. 用 EnCodec / FACodec 将语音波形转为离散 token，构建「历史 token → 未来 token」预测任务及完整训练评测流水线；训练序列预测模型并解码回语音，以 STOI、PESQ 客观指标结合主观听感评估质量；总结 token 表示、生成长度、模型容量与数据规模对预测质量的影响。
